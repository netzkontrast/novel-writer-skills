## 1. Upgrade Background

### 1.1 Core Problem

**User Feedback**:
> "Novel Writer works well for the first 30 chapters, but after chapter 30, the AI starts to lose focus and forget previous settings and rules."

**Root Cause**:
- Accumulated context in long-form novels distracts the AI's attention.
- Lack of a mandatory context-reloading mechanism.
- No systematic knowledge base support.
- Tracking of characters/plotlines relies on manual memory.

### 1.2 Target Users

- **Primary Users**: Professional authors writing long-form novels of 500,000+ words.
- **Secondary Users**: Novice authors who need systematic writing guidance.
- **Future Planning**: Architectural preparation for VSCode plugin development.

## 2. Solution Design

### 2.1 Core Architecture Upgrade

#### Knowledge Base System

**Design Philosophy**: Layered architecture, on-demand loading.

```
.claude/knowledge-base/
├── README.md              # Keyword mapping table + main index
├── genres/                # Genre knowledge bases
│   ├── romance.md        # Romance (948 lines, ~27KB)
│   ├── mystery.md        # Mystery (1123 lines, ~31KB)
│   ├── historical.md     # Historical (1127 lines, ~27KB)
│   ├── revenge.md        # Revenge (846 lines, ~22KB)
│   └── wuxia.md          # Wuxia (143 lines, ~2.8KB)
├── craft/                 # Writing craft (reserved)
└── references/            # Reference materials (reserved)
```

**Token Efficiency**:
- Traditional approach: 50 Skills × 40 tokens = ~2000 tokens
- New approach: 1 detector (100 tokens) + on-demand knowledge base (500 tokens) = 600 tokens
- **Saves 75% in token overhead**

**Keyword Auto-Activation Mechanism**:
```yaml
romance:
  keywords: [romance, love story, love, romantic, relationship arc, CP, sweet story, angst]
  auto_load: genres/romance.md

mystery:
  keywords: [mystery, suspense, detective, crime solving, puzzle, clue, truth, murderer, crime]
  auto_load: genres/mystery.md
```

#### Quality Assurance Skills

**4 Core Skills**:

1.  **setting-detector** (566 lines)
    - **Function**: Automatically detects keywords in user input and loads the corresponding knowledge base.
    - **Activation Time**: When the user mentions the story's genre, setting, or background.
    - **Example**:
        ```
        User: "I want to write a 1920s romance revenge novel."
        Detector identifies:
          - "1920s" → china-1920s.md
          - "romance" → romance.md
          - "revenge" → revenge.md
        Automatically loads 3 knowledge bases.
        ```

2.  **pre-write-checklist** (541 lines)
    - **Function**: Forces the AI to confirm that it has loaded 9 core files before executing `/write`.
    - **Problem Solved**: **The core solution to the post-chapter-30 loss of focus problem.**
    - **Mandatory Checklist**:
        ```markdown
        ✓ 1. memory/constitution.md - Writing Constitution
        ✓ 2. memory/style-reference.md - Style Reference
        ✓ 3. stories/*/specification.md - Story Specifications
        ✓ 4. stories/*/creative-plan.md - Creative Plan
        ✓ 5. stories/*/tasks.md - Current Task
        ✓ 6. spec/tracking/character-state.json - Character States
        ✓ 7. spec/tracking/relationships.json - Relationship Network
        ✓ 8. spec/tracking/plot-tracker.json - Plot Tracker
        ✓ 9. spec/tracking/validation-rules.json - Validation Rules
        ```

3.  **forgotten-elements** (147 lines)
    - **Function**: Monitors the appearance frequency of characters/plots/foreshadowing in the background.
    - **Thresholds**:
        - Character: 10 chapters without an appearance → reminder.
        - Plotline: 12 chapters with no progress → reminder.
        - Foreshadowing: 20 chapters not paid off → reminder.
    - **Reminder Example**:
        ```
        ⚠️ Character Reminder:
        "Supporting character Li Ming" has not appeared in 10 chapters (last seen: Chapter 5).
        - Should he be scheduled to appear again?
        - Or has this character's story concluded?
        ```

4.  **getting-started** (224 lines)
    - **Function**: Guides new users and introduces the seven-step methodology.
    - **Activation Condition**: When the user says "I want to write a novel," "How do I use this," etc.
    - **Content**:
        - Detailed explanation of the seven-step process.
        - FAQ.
        - Suggestions for first-time use.

## 4. Knowledge Base Content Details

### 4.1 Romance Novel Knowledge Base (romance.md)

**Core Content** (948 lines):

1.  **Relationship Arc Design**
    - First meeting → Attraction → Testing → Confirmation → Deepening → Crisis → Reconciliation → Stability.
    - Key events for each stage.
    - Pacing techniques.

2.  **Emotional Beats**
    - Designing moments of attraction (15+ classic scenarios).
    - Formulas for sweet moments.
    - Managing the intensity of angsty plotlines.

3.  **Creating Chemistry**
    - Techniques for romantic subtext in dialogue.
    - Details of body language.
    - Designing internal monologues.

4.  **Conflict Management**
    - Plausibility check for misunderstandings.
    - Correct use of third-party characters.
    - External pressure vs. internal conflict.

### 4.2 Mystery/Suspense Knowledge Base (mystery.md)

**Core Content** (1123 lines):

1.  **Fair Play Principle**
    - All clues must be presented to the reader.
    - No hiding of key information.
    - The truth must be deducible.

2.  **Clue Planting**
    - Three-layer structure: Obvious clues + subtle clues + red herrings.
    - Clue density: At least 3 valid clues every 5 chapters.
    - Retrospective validation: The solution must be self-consistent after the reveal.

3.  **Suspect Management**
    - A pool of 3-5 suspects.
    - Each must have motive, opportunity, and suspicious behavior.
    - Pacing the elimination of suspects.

4.  **The Reveal**
    - Domino-style reveal vs. single reveal.
    - Conditions for unexpected twists.
    - Foreshadowing payoff checklist.

### 4.3 Historical Novel Knowledge Base (historical.md)

**Core Content** (1127 lines):

1.  **Major Events vs. Minor Details**
    - Use major historical events as a backdrop, not the main plot.
    - Focus on the characters' choices within history.
    - Avoid a dry recitation of historical facts.

2.  **Historical White Description**
    - Concise and powerful environmental descriptions.
    - Remove modern-sounding adjectives.
    - Example comparison:
        ```
        ❌ Bad: "The magnificent palace was resplendent and awe-inspiring."
        ✅ Good: "Red walls, yellow tiles, and soaring eaves."
        ```

3.  **Creating Period Atmosphere**
    - Accuracy in clothing, etiquette, and forms of address.
    - Research into details of daily life.
    - Language style that reflects the period.

4.  **Balancing Historical Accuracy and Entertainment**
    - Core historical events should not be altered.
    - Details can be reasonably fictionalized.
    - More creative freedom with minor characters.

### 4.4 Revenge-Themed Knowledge Base (revenge.md)

**Core Content** (846 lines):

1.  **Establishing Deep-Seated Hatred**
    - The hatred must be well-justified.
    - Requires detailed setup early on.
    - The reader must empathize.

2.  **Pacing of Retribution**
    - Gradual is better than all at once.
    - Start small, then escalate.
    - Each act of retribution should be novel.

3.  **Plausibility of Power Growth**
    - "Golden fingers" (special advantages) should not be too overpowered.
    - Growth requires sacrifice.
    - Avoid mindless steamrolling.

4.  **Moral Balance**
    - Revenge should have limits.
    - Avoid indiscriminate harm.
    - Justice vs. gratification.

### 4.5 Wuxia Novel Knowledge Base (wuxia.md)

**Core Content** (143 lines, simplified version):

1.  **Jianghu Rules**
    - The spirit of xia (chivalry).
    - Clan and sect systems.
    - Feuds and relationships.

2.  **Martial Arts System**
    - Internal vs. external martial arts.
    - Techniques for describing combat.
    - Power level settings.

3.  **The Spirit of the Xia**
    - "The great xia serves the country and the people."
    - Personal grudges vs. the greater good.
    - The limits of righteous vengeance.

```
  ↓
```

**Now (v1.0.3)**:

**Value**:

## 7. Performance Optimization

### 7.1 Token Usage Efficiency

**Comparative Analysis**:

| Approach | Token Consumption | Coverage |
|---|---|---|
| Traditional (50 separate Skills) | ~2000 tokens | 50 knowledge points |
| New (layered knowledge base) | ~600 tokens | On-demand loading |
| **Savings** | **75%** | **More flexible** |

### 7.2 Scalability

**Cost of adding a new knowledge base**:
1.  Create a new file in `knowledge-base/genres/`.
2.  Add a keyword mapping in `README.md`.
3.  No code changes required.

**Example**: Adding a "Sci-Fi" knowledge base
