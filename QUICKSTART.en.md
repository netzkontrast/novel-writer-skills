# Novel Writer Skills Quick Start

## Get Started in 5 Minutes

### 1. Installation (1 minute)

```bash
npm install -g novel-writer-skills
```

### 2. Create a Project (30 seconds)

```bash
novelwrite init my-novel
cd my-novel
```

### 3. Get Started in Claude Code (3 minutes)

1. Open the `my-novel` folder in Claude Code
2. Enter the first command:

```
/constitution
```

3. Follow the AI's guidance and answer the questions
4. Once completed, continue with:

```
/specify
/clarify
/plan
/tasks
/write
```

## It's that simple!

### Auto-Activating Skills

You don't need to do anything; the following Skills will work automatically:

- 🎨 **Genre Knowledge**: Activates automatically when you mention "romance," "mystery," or "fantasy"
- ✍️ **Writing Techniques**: Applied automatically when writing dialogue or scenes
- 🔍 **Quality Checks**: Monitors in the background during the writing process

### Recommended First-Day Workflow

**Time: 2-3 hours**

```
09:00 - 09:20  /constitution  (Writing Principles)
09:20 - 10:00  /specify       (Story Specifications)
10:00 - 10:15  /clarify       (Clarify Ambiguities)
10:15 - 11:00  /plan          (Creation Plan)
11:00 - 11:30  /tasks         (Task Breakdown)
11:30 - 12:00  /write         (Start writing Chapter 1)
```

## Common First-Step Questions

**Q: Do I have to execute the commands in order?**
A: It is recommended to follow the order, but the minimum workflow is: `/constitution` → `/specify` → `/write`

**Q: Do Skills activate automatically?**
A: Yes! As long as you mention relevant content (romance, mystery, etc.), the Skills will work automatically.

**Q: Can I skip /plan?**
A: Yes, but `/write` will be more effective with `/plan` as a guide.
