# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-18

### Added

#### Core Features
- 🎯 Complete seven-step methodology Slash Commands
  - `/constitution` - Create a writing constitution
  - `/specify` - Define the story specifications
  - `/clarify` - Clarify key decisions
  - `/plan` - Develop a creation plan
  - `/tasks` - Break down the task list
  - `/write` - AI-assisted writing
  - `/analyze` - Quality validation analysis

- 📊 Tracking and Validation Commands
  - `/track-init` - Initialize the tracking system
  - `/track` - Comprehensive tracking update
  - `/plot-check` - Plot consistency check
  - `/timeline` - Timeline management
  - `/relations` - Character relationship tracking
  - `/world-check` - World-building validation

#### Agent Skills System
- 🤖 Genre Knowledge Skills
  - Romance - Romance novel conventions and emotional pacing
  - Mystery - Mystery and suspense techniques and clue management
  - Fantasy - Fantasy setting standards and world-building

- ✍️ Writing Techniques Skills
  - Dialogue Techniques - Naturalness of dialogue and character voice
  - Scene Structure - Scene construction and pacing control
  - Character Arc - Character arcs and logical development

- 🔍 Quality Assurance Skills
  - Consistency Checker - Automatic consistency monitoring
  - Workflow Guide - Seven-step methodology guidance

#### CLI Tools
- 📦 Project Management
  - `novel-skills init` - Initialize project
  - `novel-skills check` - Check environment
  - `novel-skills upgrade` - Upgrade project

- 🔌 Plugin System
  - `novel-skills plugin:list` - List installed plugins
  - `novel-skills plugin:add` - Add a plugin
  - `novel-skills plugin:remove` - Remove a plugin

#### Documentation
- 📚 Complete documentation system
  - README.md - Project Overview
  - Getting Started - Getting Started Guide
  - Commands Guide - Command Reference
  - Skills Guide - Skills Guide
  - Plugin Development - Plugin Development

### Features

- ✨ Deep integration with Claude Code
- ✨ Automatic activation mechanism for Agent Skills
- ✨ Intelligent quality check system
- ✨ Extendable plugin architecture
- ✨ Complete project templates

### Technical

- 🛠️ Implemented in TypeScript
- 🛠️ ES Module support
- 🛠️ Node.js >= 18.0.0
- 🛠️ CLI based on Commander.js
- 🛠️ Complete type definitions
